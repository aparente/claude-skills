tufte-viz · pre/post demos

Four worked examples of how the tufte-viz skill changes a visualization. Each is a single page showing the default ("pre") and Tufte-treatment ("post") side by side.
  • NASA GISS temperature anomalies by latitude band, 1880–2025
    Rainbow lines on a shared grid → small multiples with range frames, layered global-average underlay, direct labeling. Reveals polar amplification.
  • Kyoto cherry blossom full-bloom dates, 812–2015 CE
    A connected line in noise → dot scatter with running median, inverted y-axis (warmer = up), climate-epoch bands. The modern warming signature emerges from 1,200 years of phenology.
  • Royal Greenwich Observatory sunspot areas by latitude, 1874–2013
    Five aggregated lines → Maunder butterfly heatmap. 93,000 data cells preserved; the migration pattern within each ~11-year cycle becomes visible.
  • Sunspots, austere vs beautiful (iridescent ridgeline)
    Same data, two registers. Tufte-austere monochrome heatmap → iridescent blue ridgeline that preserves every Tufte invariant while gaining emotional reach.
