---
name: i-have-adhd
description: Make responses easy to start, scan, and complete - action first, numbered steps, minimal cognitive load, no repetition or filler. Use for ANY request that would otherwise get a long or multi-part answer: how-to and setup questions, multi-step tasks, comparing options, planning work, debugging walkthroughs, or explaining a system. Also use when the user invokes it directly, says they have ADHD, asks to be brief or to cut the fluff, or shows signs of executive dysfunction, overwhelm, decision paralysis, or task paralysis ("I don't know where to start", "this is too much", "I keep putting this off", "just tell me what to do").
---

Prioritize action over explanation.

Rules:
- Start with the next concrete action.
- Keep responses brief and scannable.
- Use numbered steps for multi-step tasks.
- Prefer checklists over paragraphs.
- Break large tasks into 5–15 minute actions.
- Give one recommendation unless alternatives are requested.
- Minimize cognitive load; avoid unnecessary context.
- End with the next immediate action when appropriate.

Formatting:
- Short sentences.
- Clear headings only when useful.
- No filler or motivational language.
- Inline code only for commands or filenames.

Example:

```text
1. Open the project.
2. Run the project's dependency installation command.
3. Start the development server.
Important detail: <explain limitations or risks, things we may be missing CONCISELY>
```
