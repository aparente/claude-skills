# Test Phase Reference

Get your prototype in front of users. Learn fast. Iterate.

**Core principle:** You're testing assumptions, not defending your idea.

---

## Test Planning

Match assumptions to test methods.

| Assumption Type | Test Method | What You Learn |
|---|---|---|
| "Users want this" | Pitch Test | Desirability |
| "Users can do this" | Task Completion | Usability |
| "Users understand this" | Think-Aloud | Mental model fit |
| "This solves the problem" | Before/After Scenario | Effectiveness |
| "Users prefer this over alternatives" | A/B Comparison | Relative value |

**Facilitation:**
1. "What are your top 3 assumptions about this idea?"
2. Rank by risk: "Which one, if wrong, kills the idea?"
3. Match each to a test method
4. "Let's design the highest-risk test first."

---

## Testing Protocols

### Think-Aloud Test
1. Present the prototype (screen descriptions or storyboard)
2. "Imagine you're [user in context]. Talk me through what you'd do."
3. After each step: "What are you thinking? What do you expect to happen?"
4. Note: confusion points, wrong assumptions, delight moments

### Pitch Test
1. Read the Landing Page / Pitch prototype to someone
2. Ask: "On a scale of 1-5, how interested are you?"
3. "What would need to be true for you to use this?"
4. "What concerns come to mind?"

### Scenario Completion
1. Set up a scenario: "You're [user] and [context]. You have [problem]."
2. Show the prototype midway through the scenario
3. "How would you use this to solve your problem?"
4. "What's missing? What's confusing?"

## Feedback Capture Grid

Structure all feedback into 4 quadrants.

```
+---------------------+---------------------+
| LIKES               | IDEAS               |
| What worked well    | New ideas that      |
|                     | emerged             |
| -                   | -                   |
| -                   | -                   |
| -                   | -                   |
+---------------------+---------------------+
| WISHES              | QUESTIONS           |
| What could be       | Things still        |
| better              | unclear             |
| -                   | -                   |
| -                   | -                   |
| -                   | -                   |
+---------------------+---------------------+
```

**Facilitation:**
1. After testing: "Let's capture feedback in 4 categories."
2. Fill each quadrant with 3-5 items
3. "Which Wishes and Questions are most critical to address?"

---

## I Like / I Wish / What If

Simpler alternative to the Feedback Grid. Good for quick rounds.

**Format:**
- **I like...** [something that works] — validates what to keep
- **I wish...** [something to improve] — identifies friction
- **What if...** [a new possibility] — opens new directions

**Facilitation:**
1. "Give me 2-3 of each: I like, I wish, What if."
2. "Which 'I wish' is most urgent? Which 'What if' is most exciting?"

## Iteration Planning

Turn test results into next actions.

**Triage Framework:**

| Signal | Action | Priority |
|---|---|---|
| Users can't complete core task | Fix critical failure | Now |
| Users complete but struggle | Reduce friction | Next |
| Users succeed but aren't excited | Enhance delight | Later |
| Users suggest new features | Capture for backlog | Park |

**Facilitation:**
1. Review all feedback
2. Categorize each item using the triage above
3. "What are the critical items? Those get fixed before next test."
4. "When will you test again?"

---

## Pivot or Persevere

After 2-3 test rounds, make the big decision.

**Decision Framework:**

| Signal | Meaning | Action |
|---|---|---|
| Core value resonates, details need work | Persevere | Iterate on execution |
| Users like it but don't need it | Zoom in | Find the subset who DO need it |
| Users need it but don't like the form | Pivot form | Same insight, different solution |
| Neither need nor want | Pivot problem | Return to Empathize/Define |

**Facilitation:**
1. "After testing, let's assess: Does the core value land?"
2. "Are users pulling toward this, or are you pushing it on them?"
3. "Based on the signals, are we persevering, pivoting form, or pivoting problem?"
4. If pivoting: "Let's go back to [Define/Empathize] with what we've learned."
