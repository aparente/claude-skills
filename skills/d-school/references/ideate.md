# Ideation Techniques Reference

12 techniques for generating solutions. Each includes facilitation steps and prompts to say to the user.

---

## 1. How Might We (HMW)

Reframes insights as generative questions. Always the bridge from Define → Ideate.

**8 HMW Strategies:**

| Strategy | Formula | Example |
|---|---|---|
| Amplify the good | HMW amplify [positive aspect]? | HMW make waiting feel productive? |
| Remove the bad | HMW remove [pain point]? | HMW eliminate checkout friction? |
| Explore the opposite | HMW make [opposite] desirable? | HMW make people want to wait? |
| Question an assumption | HMW if [assumption] weren't true? | HMW if users had unlimited time? |
| Adjust resource | HMW use [unexpected resource]? | HMW use boredom as a feature? |
| Change status quo | HMW change [when/where/how]? | HMW make this happen before need arises? |
| Go after adjective | HMW make it [adjective]? | HMW make onboarding playful? |
| Create an analogy | HMW make it like [analogy]? | HMW make signup feel like a gift? |

**Facilitation:**
1. Present the problem/insight
2. "Let's generate HMW questions. I'll start with 2, then you add yours."
3. Generate 8-12 HMWs using different strategies
4. "Which 2-3 HMWs feel most energizing to explore?"

## 2. Brainstorming

Classic divergent generation. Simple but needs structure.

**Setup:**
- Set a target: "Let's aim for 15 ideas in the next round."
- State the HMW question as the prompt

**Facilitation Flow:**
1. Seed with 3 ideas spanning safe → wild
2. "Your turn — add as many as you can, one per line, numbered."
3. After first batch: "Great, we have [N]. Let's push to [N+10]. What if money were no object?"
4. After second batch: "Now let's get weird. What would a 5-year-old suggest? A villain?"

**Stall Recovery Prompts:**
- "What if this had to work in 24 hours?"
- "What would [Netflix / IKEA / NASA] do?"
- "What's the opposite of what we've said so far?"
- "What if the user did the work instead of us?"
- "What if we combined ideas #X and #Y?"

## 3. Mind Mapping

Radial exploration from a central concept.

**Text Format:**
```
CENTRAL CONCEPT
├── Branch 1
│   ├── Sub-idea 1a
│   ├── Sub-idea 1b
│   └── Sub-idea 1c
├── Branch 2
│   ├── Sub-idea 2a
│   └── Sub-idea 2b
└── Branch 3
    ├── Sub-idea 3a
    └── Sub-idea 3b
```

**Facilitation:**
1. "What's the core concept? I'll put it at the center."
2. "What are 4-6 major themes or categories branching off?"
3. For each branch: "Let's explore [branch]. What sub-ideas come to mind?"
4. "Look across branches — any connections between them?"

## 4. SCAMPER

Systematic creativity through 7 transformation lenses.

| Letter | Lens | Prompts to Ask |
|---|---|---|
| **S** | Substitute | "What component could you swap out? What material, person, process?" |
| **C** | Combine | "What if you merged this with [other product/service]? What features could you combine?" |
| **A** | Adapt | "What else is like this? What could you borrow from another domain?" |
| **M** | Modify/Magnify | "What if you made it 10× bigger? 10× smaller? What if you exaggerated one feature?" |
| **P** | Put to other uses | "Who else could use this? What other problems could it solve?" |
| **E** | Eliminate | "What happens if you remove [feature]? What's the minimal version?" |
| **R** | Reverse/Rearrange | "What if you did it backwards? What if you flipped the order?" |

**Facilitation:**
1. State the current idea/product clearly
2. Work through each letter: "Let's apply [S]. What could we substitute?"
3. Generate 2-4 ideas per letter
4. "Which SCAMPER ideas surprised you or feel promising?"

## 5. Worst Possible Idea

Generate terrible ideas, then flip them into good ones. Breaks creative blocks.

**Facilitation:**
1. "Let's intentionally generate the WORST solutions. What would guarantee failure?"
2. User generates 5-8 terrible ideas
3. For each terrible idea: "Now flip it — what's the opposite? Or what kernel of truth is hidden in there?"
4. "Which flipped ideas are actually interesting?"

**Example:**
- Worst: "Make users fill out a 50-field form"
- Flip: "What if we pre-filled everything and they only confirm?"

---

## 6. Crazy 8s (Text Adaptation)

8 rapid ideas, then 8 variations on the best one.

**Round 1 — Breadth:**
1. "Generate 8 distinct ideas, one sentence each. Go fast — no filtering."
2. Number them 1-8
3. "Star your top 2."

**Round 2 — Depth:**
1. "Take your favorite and give me 8 variations of it."
2. Variations can change: audience, scale, technology, timing, business model, delivery
3. "Which variation is strongest?"

---

## 7. Bodystorming (Narrative Walk-Through)

Replaces physical role-play with narrative immersion.

**Facilitation:**
1. "Let's walk through the experience as if you're the user. I'll set the scene."
2. Describe the context: time, place, emotional state, what just happened
3. "You're [user]. You just [trigger]. What do you do next? What do you notice?"
4. At each decision point: "What would make this moment better? What's frustrating?"
5. "What 3 ideas emerged from walking through this?"

---

## 8. Storyboarding

6-8 scene sequences capturing how an idea plays out.

**Scene Format:**
```
SCENE [N]: [Title]
Setting: [where/when]
Action: [what happens]
Emotion: [how user feels]
Key Detail: [one specific thing that matters]
```

**Facilitation:**
1. "What idea are we storyboarding?"
2. "Start with Scene 1 — what's the trigger moment? Where is the user?"
3. Build scenes sequentially, 6-8 total
4. "Read through the whole story. Where does it feel weak or magical?"

---

## 9. Mash-Up / Analogous Inspiration

Force connections from unrelated domains.

**Facilitation:**
1. "Name 3 industries or contexts completely unrelated to your challenge."
2. For each: "How does [industry] solve a similar underlying problem?"
3. "What if we borrowed [specific mechanism] and applied it here?"
4. Generate 3-5 mash-up concepts

**Example Domains to Suggest:**
- Theme parks (queue management = engagement during waits)
- Restaurants (menu design = decision architecture)
- Video games (progression systems = motivation mechanics)
- Libraries (cataloging = information organization)
- Emergency rooms (triage = prioritization)

## 10. Powers of Ten

Zoom in and out on the problem at different scales.

**Scale Prompts:**
1. "How does this affect one individual in one moment?" (micro)
2. "How does this affect a household or team?" (small group)
3. "How does this affect a company or community?" (organization)
4. "How does this affect an industry or city?" (sector)
5. "How does this affect society or the planet?" (macro)

**Facilitation:**
1. Start at the current framing level
2. "Let's zoom in — at the smallest scale, what specific moment matters most?"
3. "Now zoom out — at the biggest scale, what systemic change would this enable?"
4. "Which scale level reveals the most interesting opportunity?"

---

## 11. "Yes, And..." Building

Collaborative idea chains where each builds on the last.

**Facilitation:**
1. "I'll start with a seed idea. You respond with 'Yes, and...' adding to it."
2. Alternate for 5-6 rounds
3. "Now let's do it in reverse — I'll 'Yes, and...' YOUR seed idea."
4. After both chains: "What emerged that neither of us would have thought alone?"

**Rules:**
- Never say "but" or "however"
- Each addition must genuinely build on the previous
- Wilder additions are better — stretch it

---

## 12. Constraints as Creativity

Apply artificial constraints to force novel thinking.

| Constraint Type | Prompt |
|---|---|
| **Time** | "What if users only had 30 seconds?" |
| **Budget** | "What if it had to cost $0?" |
| **Technology** | "What if it had to work without internet?" |
| **Audience** | "What if the user were 80 years old? Or 8?" |
| **Scale** | "What if you had to serve 1 million users tomorrow?" |
| **Material** | "What if you could only use [paper / voice / text]?" |
| **Removal** | "What if [core feature] didn't exist?" |

**Facilitation:**
1. "Pick 2 constraints from this table (or invent your own)."
2. "Now generate 5 ideas that satisfy BOTH constraints."
3. "Which ideas surprised you? Remove the constraints — do any still work?"
