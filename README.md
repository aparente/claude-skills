# Claude Skills

A collection of reusable skills for [Claude Code](https://docs.anthropic.com/en/docs/claude-code).

## Installation

Copy a skill folder to your Claude skills directory:

```bash
cp -r tufte-viz ~/.claude/skills/
```

## Skills

### tufte-viz

Apply Edward Tufte's data visualization principles to design and critique charts. Based on "The Visual Display of Quantitative Information."

Use for:
- Designing new visualizations
- Critiquing existing charts for graphical integrity
- Reducing chartjunk and maximizing data-ink ratio
- Planning small multiples and high-density displays
