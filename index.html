claude-skills

Reusable skills and slash commands for Claude Code.

Skills

  • tufte-viz — Tufte data-visualization principles
    Includes four worked pre/post demos. Source: skills/tufte-viz/
  • d-school — Stanford d.school design-thinking facilitator
    All five phases (Empathize, Define, Ideate, Prototype, Test) with 12 structured techniques.
  • concert-playlist-builder — Extract artists from lineups, build playlists

Commands

  • /wrapup — End-of-session git workflow
    Commit → review → cleanup → commit → push, with the work committed first as a safety net.
  • /handoff [title] — Session continuity file generator
    Writes a structured markdown handoff for clean pickup in the next session.
  • /fight [target] — Dual-model red team
    Claude and Gemini deployed as adversarial agents on code, claims, or plans — finds more bugs and assumption failures than either model alone. Requires the gemini CLI.
Source: github.com/aparente/claude-skills
